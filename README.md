# javascript-dom-todo-list
A simple To-Do List web application built using HTML, CSS, and JavaScript. It allows users to add, complete, delete, and filter tasks (All, Pending, Completed) without using any external libraries.
Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter All, Pending and Completed tasks

Technologies Used

- HTML
- CSS
- JavaScript

Project Demo

"View CodePen Project" (https://codepen.io/suba-Sri-the-encoder/pen/KwmXwyj)

Learning Outcome

Learned JavaScript DOM manipulation, event handling and task filtering.

Conclusion

This project demonstrates the basic concepts of JavaScript DOM through a simple To-Do List application.
